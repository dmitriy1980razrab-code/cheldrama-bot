# Чат бот Челябинского театра драмы

Автономный чат бот без внешних языковых моделей. Источник сведений о спектаклях,
афише и артистах — официальный сайт https://www.cheldrama.ru/.

## Текущий этап

Создано ядро распознавания основных запросов и начальная схема базы данных.
Подключения сайта, VK и MAX будут отдельными адаптерами и не изменят логику ядра.

## Запуск тестов

```bash
python -m unittest discover -s tests -v
```

## Обновление локальной базы

```bash
python scripts/sync_affiche.py
```

База создаётся в `data/theatre.sqlite3`. Повторный запуск не создаёт дубли.

Полный действующий репертуар загружается отдельно:

```bash
python scripts/sync_repertoire.py
python scripts/sync_play_details.py
```

Афиша отвечает за даты показов, а репертуар — за полный список действующих постановок.

## Локальный диалог

После обновления базы:

```bash
python scripts/chat_local.py
```

Поддерживаются ближайшие спектакли, запросы на сегодня, завтра, конкретную дату
и ближайшие выходные. После загрузки подробностей поддерживаются запросы по названию,
аннотация, режиссёр, состав, жанр, дни недели и новогодняя кампания.


## Ограничения первой версии

- внешние GPT не используются;
- Yandex Cloud не требуется;
- обновление пока запускается командой вручную;
- персональные данные и подписки будут добавлены отдельным этапом.
