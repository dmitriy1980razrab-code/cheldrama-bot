# Подготовка серверного размещения

Проект рассчитан на внешний Linux-сервер с Docker. Конкретный облачный провайдер
пока не выбран и не требуется для локальной разработки.

## Что хранится где

- исходный код и история изменений — в GitHub;
- рабочая SQLite-база и технический журнал — в постоянном Docker-томе сервера;
- бот работает круглосуточно и не зависит от ноутбука разработчика;
- резервное копирование во внешнее хранилище подключается при выборе сервера.

## Будущий запуск на сервере

Репозиторий размещается в `/opt/cheldrama-bot`, затем выполняются:

```bash
docker compose build
docker compose --profile jobs run --rm updater
docker compose up -d bot
```

Порт бота доступен только на самом сервере (`127.0.0.1:8080`). Публичный HTTPS
будет подключён через обратный прокси после получения домена и согласования с
администратором сайта.

## Автоматическое обновление

Файлы `deploy/systemd/cheldrama-update.service` и
`deploy/systemd/cheldrama-update.timer` предназначены для системного таймера Linux.
Он запускает обновление ежедневно в 04:00 и выполняет пропущенный запуск после
включения сервера. Установка таймера выполняется только при развёртывании сервера.

## Резервные копии

Сервер ежедневно создаёт согласованный снимок SQLite после обновления базы. Копия
проверяется, сжимается и получает файл контрольной суммы SHA-256. В отдельном
Docker-томе сохраняются 14 последних копий.

Перед рабочим запуском этот том подключается к зашифрованному внешнему хранилищу.
Способ передачи выбирается вместе с сервером; секреты и ключи не хранятся в GitHub.

## Доступ с другого компьютера

Для продолжения разработки достаточно войти в GitHub и клонировать репозиторий.
Для управления работающим ботом позднее будут выданы отдельные защищённые доступы
к серверу. Рабочая база не хранится на компьютере разработчика.
