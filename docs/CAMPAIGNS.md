# Рекламные кампании

Модуль кампаний работает только с активными подписчиками, которые отдельно разрешили
рекламные сообщения. Реальная отправка в VK и MAX будет подключена после получения
официальных доступов.

## Возможности

- выбор одного канала или одновременно VK и MAX;
- выбор аудитории по спектаклю, артисту или жанру;
- просмотр имени, ID канала и предпочтений выбранных получателей;
- автоматическое исключение пользователей без рекламного согласия;
- автоматическое исключение недавно получавших рекламу;
- обязательное подтверждение кампании перед планированием;
- журнал создания, просмотра, подтверждения и планирования;
- журнал доступа к персональным карточкам.

## Последовательность

1. Администратор создаёт черновик и задаёт аудиторию.
2. Система показывает предварительный список и количество по каналам.
3. Уполномоченный сотрудник проверяет текст и подтверждает кампанию.
4. Подтверждённая кампания получает будущие дату и время отправки.
5. Перед фактической отправкой адаптер повторно проверит статус подписки и согласия.

Сейчас реализованы пункты 1–4 без внешней отправки. Веб-интерфейс административной
панели, вход с двухфакторной авторизацией и адаптеры каналов добавляются отдельно.
