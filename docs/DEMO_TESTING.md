# Демонстрационная проверка подписок

Команда запускает полностью локальную имитацию VK и MAX:

```bash
python scripts/demo_subscriptions.py
```

Сценарий создаёт только вымышленных пользователей:

- Анна в VK подписана на «Гамлета» и разрешила рекламные сообщения;
- Борис в MAX подписан на «Чайку» и разрешил рекламные сообщения;
- Мария в VK подписана на «Гамлета», но не разрешила рекламу.

Проверяются сервисное напоминание, рекламная выборка по предпочтению, исключение
пользователя без рекламного согласия, подтверждение кампании и отписка. Тестовый
адаптер не выполняет сетевых запросов. Временная база автоматически удаляется.

## Демонстрационная административная панель

```bash
python scripts/run_admin_demo.py
```

Команда выводит адрес `http://127.0.0.1:8090/admin` и случайный одноразовый пароль.
Панель доступна только с текущего компьютера. В ней можно увидеть вымышленных
подписчиков, их ID, согласия и предпочтения, затем создать тестовую кампанию и
посмотреть выбранных получателей. После просмотра кампанию можно подтвердить и
назначить будущие дату и время по часовому поясу Челябинска. Сообщения не отправляются.

Для остановки используется `Ctrl+C`. После остановки временная база удаляется.
Рабочая серверная панель позднее получит HTTPS, постоянные учётные записи и
двухфакторную авторизацию.

## Диалог подписки VK/MAX

```bash
python scripts/demo_subscription_flow.py
```

Команда показывает последовательность сообщений и кнопок: предложение подписки,
согласие на персональные данные, отдельное разрешение сервисных уведомлений,
необязательное рекламное согласие, настройку уведомлений и отписку. В примере
пользователь отказывается от рекламы, но сохраняет сервисную подписку.
